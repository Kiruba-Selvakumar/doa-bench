# Reference datasets

Two datasets generated by the original MATLAB implementation. They are the only data
against which bit-level agreement with MATLAB can be tested: a Python generator cannot
reproduce MATLAB's random stream. `SHA256SUMS` pins both files.

Both use N = 4 sensors at d = λ/2, L = 100 snapshots, 200 independent trials per
condition, SNR = 10 dB (σ² = 0.1, unit source power) and true DOAs [-20.3°, 19.7°]. The
DOAs are deliberately off the 1° grid, so a coarse search cannot land exactly on the truth
and report zero error.

| file | conditions | seed |
|---|---|---|
| `doa_dataset_correlated.mat` | source correlation ρ ∈ {0, 0.5, 0.9, 0.95, 0.99} | 20260904 |
| `doa_dataset_uncorrelated.mat` | ρ = 0 only | 20260905 |

`X` has shape N x L x trials x conditions (3-D in the single-condition file, since MATLAB
drops the trailing singleton). Trial `t` of condition `c` gives R̂ = X[:, :, t, c] X[:, :, t, c]ᴴ / L.

The two files store their scalar metadata with different dtypes: float64 in one, and
uint8/int32 in the other, because MATLAB's `-v7` format compacts integer-valued doubles.
`doabench.io.load_reference_mat` converts everything to plain Python types before use.
